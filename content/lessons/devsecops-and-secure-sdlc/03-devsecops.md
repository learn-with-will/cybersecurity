# DevSecOps

**DevSecOps** extends DevOps by making security a **shared responsibility** built into automated delivery, not a gate owned by a separate team at the end. Its core ideas:

- **Automate security checks** inside the **CI/CD pipeline** so every commit is tested.
- **Fast feedback** to developers (in the pull request, not weeks later).
- **Guardrails, not gates** — secure defaults and automated checks that help teams move safely, rather than manual bottlenecks.
