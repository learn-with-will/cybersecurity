# The Secure SDLC and "Shift Left"

The **software development lifecycle (SDLC)** runs from requirements → design → build → test → deploy → operate. A **secure SDLC** adds security to **every** stage rather than a single review at the end.

**Shift left** means moving security **earlier** in that timeline. A flaw caught in design or code review costs a fraction of the same flaw found in production, so the goal is to give developers fast feedback while they're still in the code.
