# Key Takeaways

- A **secure SDLC** builds security into every stage; **shifting left** catches flaws early where they're cheapest to fix.
- **DevSecOps** integrates automated security into **CI/CD** as a shared responsibility, favoring **guardrails over gates**.
- Layer **SAST (code)**, **SCA (dependencies)**, **DAST (running app)**, and **secret/IaC scanning** — each finds different flaws.
- Defend the **software supply chain** (OWASP A08) with dependency management, **SBOMs**, **signing**, and build **provenance (SLSA)**.
