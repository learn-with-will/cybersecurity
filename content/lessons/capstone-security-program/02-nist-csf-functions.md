# A framework as the skeleton

We'll use the **NIST Cybersecurity Framework 2.0** functions (Lesson 23) as the organizing structure, because they cover the full arc from leadership to recovery:

```text
 GOVERN   —  set direction, ownership, risk appetite, policy
 IDENTIFY —  know your assets, risks, and threats
 PROTECT  —  the controls that prevent/limit harm
 DETECT   —  see attacks and anomalies
 RESPOND  —  act on incidents
 RECOVER  —  restore and learn
```

Every control you learned lives in one of these — and the functions run **continuously**, feeding back into each other.
