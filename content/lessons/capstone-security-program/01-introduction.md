# Why It Matters

Security fails when it's a pile of disconnected tools. It succeeds when controls form **layers that reinforce each other** and are **governed, prioritized, and measured**. 

This capstone ties the whole course together: every earlier lesson is a piece, and here you assemble them into one program using a framework as the skeleton. If you can place each control in the right function and explain how the layers back each other up, you've understood cybersecurity as a system — not a checklist.

# Learning Objectives

By the end of this lesson you will be able to:

- Organize security work using the **NIST CSF 2.0 functions**.
- **Map** the course's controls into a single defense-in-depth program.
- **Prioritize** a security roadmap by risk with limited resources.
- Choose meaningful **metrics** to know if the program works.
- Design a coherent program for a realistic organization.
