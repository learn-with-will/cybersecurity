# The program is a loop

Finally, a security program is never "done." Threats evolve, the business changes, and each incident and review feeds back into GOVERN and IDENTIFY. This is the identify-protect-detect-respond-recover cycle, now with a Govern function steering it — the same idea at the scale of a whole organization.

# Summary

- A real **security program** is a governed, prioritized, measured **whole** — not a pile of tools.
- The **NIST CSF 2.0 functions** give the skeleton; every lesson in this course maps into one of them.
- **Defense in depth across functions** means no single failure is fatal.
- **Prioritize the highest-leverage basics first**, **measure outcomes**, and run the program as a **continuous, improving loop**.
