> **In one line:** Security theater provides the appearance of protection while ignoring actual vulnerabilities.

## The idea

Security theater occurs when effort is spent on visible controls that make people *feel* secure but do nothing to reduce real risk. An example is installing a complex badge reader at a door that is propped open all day. The security measure is useless because it doesn't address the primary risk. 

Always tie your security controls to real assets and verified threats.

## See it

| Control | Provides | Reality |
| :--- | :--- | :--- |
| Badge reader | Visible security | Door left propped open |
| Unused software | "We have protection" | Unpatched vulnerability |

## Remember
- Security theater provides false reassurance without addressing real risks.
- Always verify that controls actually mitigate a identified threat.
- Focus on functional, effective security over superficial optics.
