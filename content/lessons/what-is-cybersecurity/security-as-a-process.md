> **In one line:** Because threats evolve, security is a continuous cycle of assessment, protection, and response rather than a single product.

## The idea

Security is not a product you buy; it is an ongoing process. Since software changes and attackers adapt, you must follow a cycle:

1. **Identify**: What assets do you have?
2. **Protect**: What controls mitigate the risk?
3. **Detect**: How do you know if something goes wrong?
4. **Respond**: What is your plan if an incident occurs?
5. **Recover**: How do you return to normal operations?

This cycle is the backbone of frameworks like the NIST Cybersecurity Framework.

## See it

```flow
Identify -> Protect -> Detect -> Respond -> Recover -> Identify
```

## Remember
- Security is a continuous cycle of improvement, not a one-time setup.
- The NIST Cybersecurity Framework outlines these core functions.
- You must be prepared to detect and recover from issues, not just prevent them.
